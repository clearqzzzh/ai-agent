# 宠物商品选购指南

## 一、主粮选购

### 1.1 狗粮选购
- 按体型选择：小型犬（10kg以下）颗粒小、热量高；大型犬（25kg以上）颗粒大、含关节保护成分
- 按年龄选择：幼犬粮（高蛋白高钙促发育）、成犬粮（营养均衡）、老年犬粮（低脂易消化）
- 看配料表前三位：必须是明确的肉类来源（鸡肉、牛肉、鱼肉），不是"肉粉""肉骨粉""动物副产品"
- 粗蛋白含量：成犬≥18%，幼犬≥22%（干粮基准）
- 避免成分：人工色素（Red 40、Yellow 5）、人工防腐剂（BHA、BHT、乙氧基喹啉）、玉米/小麦（常见过敏原）
- 特殊需求粮：低敏粮（单一蛋白源如无谷三文鱼）、处方粮（需兽医指导）、减肥粮（高纤维低脂肪）
- 常见品牌定位：
  - 高端：渴望（Orijen）、爱肯拿（Acana）、纽顿（Nutram）、GO!
  - 中端：皇家（Royal Canin）、冠能（Pro Plan）、比瑞吉
  - 性价比：伯纳天纯、网易严选、麦富迪

### 1.2 猫粮选购
- 猫是严格肉食动物，蛋白质需求比狗高得多
- 粗蛋白含量：成猫≥26%，幼猫≥30%（干粮基准），越高越好
- 配料表前三位：必须是动物性蛋白，不是谷物或植物蛋白
- 牛磺酸：猫粮必须含有（缺乏导致心肌病和失明），正规猫粮都会添加
- 避免成分：谷物含量过高的粮（玉米、小麦排在前面的）、人工诱食剂
- 干粮 vs 湿粮：干粮方便储存、有助牙齿清洁；湿粮水分高、适口性好、适合不爱喝水的猫
- 建议搭配喂食：70%干粮+30%湿粮，兼顾营养和水分摄入
- 常见品牌定位：
  - 高端：渴望（Orijen）、纽翠斯（Nutrience）黑钻、GO!、爱肯拿
  - 中端：皇家（Royal Canin）、百利（Instinct）、纽顿
  - 性价比：网易严选、高爷家、猫大圣

### 1.3 换粮方法
- 必须用7-10天渐进式换粮，突然换粮会导致腹泻呕吐
- 第1-2天：旧粮75% + 新粮25%
- 第3-4天：旧粮50% + 新粮50%
- 第5-6天：旧粮25% + 新粮75%
- 第7天起：完全新粮
- 换粮期间观察排便情况，软便则放慢过渡速度

## 二、零食选购

### 2.1 狗狗零食
- 训练零食：小颗粒、低热量、软质（一口吞下不打断训练节奏）
- 磨牙零食：牛皮骨、鹿角、牛蹄筋（注意大小，太小有吞咽风险）
- 冻干零食：纯肉冻干（鸡胸肉、三文鱼）营养保留好，适合挑食的狗
- 洁牙棒：选择大小匹配的，太硬（鹿角/蹄类）可能崩牙
- 避免零食：人用零食（高盐高糖）、含木糖醇的任何食品、生皮制品（消化困难）

### 2.2 猫咪零食
- 冻干零食：纯肉冻干（鸡肉、三文鱼、鹌鹑）猫接受度最高
- 猫条：液态零食，互动神器，但不要喂太多（容易养成只吃零食不吃粮的习惯）
- 猫草/化毛膏：帮助排出毛球，建议每周2-3次
- 猫薄荷：不是所有猫都有反应（约30%的猫对猫薄荷无感），幼猫通常无反应
- 避免零食：生鱼（含硫胺素酶破坏维生素B1）、牛奶、巧克力、葡萄

### 2.3 零食喂食原则
- 零食热量不超过每日总热量摄入的10%
- 零食不能替代正餐的营养
- 训练时零食要及时给（行为发生后1-2秒内），延迟奖励无效
- 如果宠物变得挑食不吃粮→减少零食量或暂停零食

## 三、日用品选购

### 3.1 食盆水盆
- 材质推荐：不锈钢（耐用好清洗）或陶瓷（重不容易翻）
- 不推荐塑料碗：容易刮花藏细菌，导致宠物下巴痘（毛囊炎）
- 慢食碗：适合吃饭太快的宠物，有凸起设计减慢进食速度
- 升降碗：大型犬/老年犬/关节炎宠物推荐，减少低头对颈椎的压力
- 自动饮水机：适合上班族/猫咪（流动水吸引猫多喝水），每周清洗一次

### 3.2 窝/垫/笼
- 狗窝：可拆洗、防滑底、大小合适（宠物能完全伸展）
- 猫窝：猫不一定睡窝，但喜欢高处和封闭空间（猫抓板+猫爬架更实用）
- 航空箱：选择比宠物大一号的尺寸，IATA认证的可用于航空托运
- 笼子/围栏：幼犬训练必备，大小让狗能站立转身即可（太大失去安全感）
- 材质安全：确保无小零件可被啃咬吞食，缝线牢固

### 3.3 牵引装备
- 胸背带 vs 项圈：胸背带更推荐（不压迫气管，适合所有犬种）
- 项圈：适合短鼻犬（法斗、巴哥）和已训练好不拉的狗，挂身份牌
- 牵引绳：标准长度1.2-1.8米，不建议用伸缩绳（失控风险高）
- 材质：尼龙（轻便耐用）、皮革（手感好但贵）、反光材质（夜间安全）

### 3.4 猫砂
- 豆腐砂：环保可冲厕所、粉尘小、结团好，但价格较高
- 膨润土砂：结团最强、价格低，但粉尘大、不能冲厕所
- 松木砂：除臭好、粉尘小，但结团差、需要双层猫砂盆
- 水晶砂（硅胶）：吸臭力强、轻便，但脚感差、部分猫不接受
- 混合砂：豆腐砂+膨润土混合，兼顾两者优点
- 选择原则：猫喜欢最重要（大部分猫偏好细颗粒、无香味）

## 四、护理用品选购

### 4.1 沐浴露
- 必须选宠物专用，人用产品pH值不匹配
- 通用型：适合健康皮肤，日常清洁
- 敏感肌型：无香料、无色素、低刺激配方
- 药用型：含氯己定/酮康唑等成分，治疗皮肤病（需兽医指导）
- 免洗型：泡沫/喷雾，适合怕水的猫或不能洗澡的情况
- 护毛素：长毛犬种洗澡后使用，减少打结

### 4.2 驱虫产品
- 体内驱虫药：
  - 拜宠清（Bayer）：广谱，驱蛔虫/钩虫/绦虫
  - 犬心保（Heartgard）：预防心丝虫+驱蛔虫/钩虫
  - 海乐妙（Virbac）：广谱体内驱虫
- 体外驱虫药：
  - 福来恩（Frontline）：滴剂，驱跳蚤蜱虫
  - 大宠爱（Revolution）：滴剂，体内外同驱（跳蚤+心丝虫+耳螨）
  - 尼可信（NexGard）：口服，驱跳蚤蜱虫
- 选择原则：按月龄/体重选剂量，猫狗产品不能混用

### 4.3 口腔护理
- 宠物专用牙膏：酶解型牙膏（含酶分解牙菌斑），鸡肉/牛肉口味
- 牙刷：手指套式（适合初学者）或长柄式（清洁更彻底）
- 洁牙玩具：橡胶材质带凸起，啃咬时清洁牙齿
- 饮水添加剂：无味无色加入饮水，抑制口腔细菌

## 五、保健品选购

### 5.1 常见保健品
- 鱼油（Omega-3）：改善皮肤毛发、抗炎、保护关节，几乎所有宠物都适合
- 益生菌：调理肠胃，换粮/腹泻/抗生素治疗后使用
- 卵磷脂：改善毛发质量，适合毛色暗淡/掉毛严重的宠物
- 关节保健品（葡萄糖胺+软骨素）：大型犬、老年犬、已有关节问题的犬种
- 化毛膏/猫草：帮助猫排出毛球，长毛猫必备
- 赖氨酸：猫用，辅助抵抗猫鼻支（疱疹病毒）
- 营养膏：幼宠/病后恢复/老年宠物补充能量

### 5.2 选购原则
- 保健品不是药，不能治疗疾病，只能辅助
- 选择宠物专用产品，人用保健品成分和剂量不适合
- 看成分表：有效成分含量是否达标
- 不要同时添加多种保健品，一次加一种观察2周
- 咨询兽医后再给老年/怀孕/有慢性病的宠物添加保健品

## 六、玩具选购

### 6.1 狗狗玩具
- 磨牙玩具：橡胶材质（Kong经典款），可以塞零食增加趣味性
- 拔河玩具：绳结玩具，互动性强，注意定期更换（绳子散开可能吞食）
- 寻回玩具：球类、飞盘，适合精力旺盛的犬种
- 益智玩具：漏食球、拼图玩具，消耗脑力减少拆家
- 安全原则：玩具不能小于宠物嘴巴（吞咽风险），定期检查有无破损

### 6.2 猫咪玩具
- 逗猫棒：羽毛/铃铛/布条类，模拟猎物运动，每天互动10-15分钟
- 猫抓板：瓦楞纸/剑麻材质，多放几个在猫咪喜欢抓的位置
- 猫爬架：满足攀爬/磨爪/休息/观察的需求，高度至少1.5米
- 自嗨玩具：电动老鼠、轨道球，适合独处时解闷
- 猫隧道：满足钻洞天性，可折叠收纳
- 安全原则：避免线绳类玩具无人看管时使用（缠绕风险），小零件容易脱落的玩具及时丢弃

## 七、智能设备

### 7.1 自动喂食器
- 适合场景：上班族、经常加班、定时定量喂食需求
- 选择要点：容量够3-5天、出粮口不卡粮、有干燥密封功能、支持App远程操控
- 注意：不能完全替代人工，每天仍需检查是否正常运行

### 7.2 自动猫砂盆
- 适合场景：讨厌铲屎、经常不在家
- 选择要点：安全性（防夹设计最重要）、适用猫砂类型、清洗方便程度
- 注意：部分猫不适应自动猫砂盆的声音，需要适应期

### 7.3 宠物摄像头
- 适合场景：上班时查看宠物状态、远程互动
- 功能：双向语音、投食功能、移动侦测、夜视
- 选择要点：画质清晰、连接稳定、App易用

### 7.4 GPS定位器
- 适合场景：容易走失的狗（猎犬类）、户外探险
- 类型：实时GPS追踪器（需SIM卡月费）、AirTag等蓝牙定位器（无实时追踪但可定位最后位置）
- 选择要点：续航时间、防水等级、重量（不超过宠物体重的5%）
