# 新手养宠指南

## 一、养宠前的准备

### 1.1 自我评估
- 时间：每天至少1-2小时陪伴时间（遛狗、互动、清洁）
- 经济：月均支出 500-2000 元（食物+驱虫+日用品+医疗储备金）
- 住房：租房需确认房东/合租室友是否允许养宠
- 体力：大型犬每天需要1-2小时户外运动，是否承受得住
- 耐心：幼宠会乱咬、随地大小便、半夜叫唤，至少需要2-4周适应期
- 长期承诺：猫寿命12-18年，狗寿命10-15年，是一辈子的责任

### 1.2 品种选择建议
- 第一次养狗推荐：泰迪/贵宾（聪明不掉毛）、柯基（活泼体型适中）、比熊（温顺低敏）、拉布拉多（友善好训练）
- 第一次养猫推荐：英短（性格稳定）、美短（亲人活泼）、布偶（温顺粘人）、中华田园猫（体质好适应力强）
- 不建议新手养：哈士奇（精力旺盛拆家）、边牧（需要大量运动和脑力刺激）、暹罗猫（叫声大需求多）
- 领养代替购买：流浪动物救助中心可以领养，通常已做绝育和疫苗

### 1.3 接宠物回家前的物资准备
必备物品清单：
- 食物：与原来吃的一样品牌和口味的粮（换粮需过渡7天）
- 食盆水盆：不锈钢或陶瓷材质，塑料碗容易滋生细菌导致下巴痘
- 猫砂盆+猫砂（养猫）/ 尿垫+围栏（养幼犬）
- 窝/垫子：放在安静角落，让宠物有安全感
- 牵引绳+胸背带（养狗）：出门必备
- 指甲钳、梳子、沐浴露等基础护理用品
- 玩具：磨牙玩具（狗）、逗猫棒/球（猫）
- 航空箱/猫包：就医、出行必备

## 二、幼犬喂养（2-12月龄）

### 2.1 饮食安排
- 2-3月龄：每天喂4次，用温水将幼犬粮泡软
- 3-6月龄：每天喂3次，逐渐减少泡水量过渡到干粮
- 6-12月龄：每天喂2次，完全干粮
- 喂食量参考粮袋说明，按体重和月龄调整
- 定时定量喂食，每次15分钟不吃就收走，培养规律饮食习惯

### 2.2 禁忌食物
- 巧克力（可可碱致死）、葡萄/葡萄干（肾衰竭）、洋葱/大蒜（溶血性贫血）
- 木糖醇（无糖口香糖中含有的，导致低血糖和肝衰竭）
- 鸡骨/鱼骨（刺穿消化道）、生鸡蛋（沙门氏菌）
- 牛奶（乳糖不耐受导致腹泻）、澳洲坚果（肌肉震颤）
- 人用药物（对乙酰氨基酚/布洛芬对猫狗剧毒）

### 2.3 疫苗计划（详见疫苗指南）
- 6-8周龄：第一针多联疫苗
- 10-12周龄：第二针多联疫苗
- 14-16周龄：第三针多联疫苗 + 狂犬疫苗
- 完成全部疫苗前不要带出门社交，不要洗澡

### 2.4 驱虫
- 体内驱虫：2周龄开始，每2周一次到12周龄，之后每月一次到6月龄，然后每3个月一次
- 体外驱虫：每月一次（尤其春夏季节）
- 驱虫药需按体重选择剂量，称体重后再给药

## 三、幼猫喂养（2-12月龄）

### 3.1 饮食安排
- 2-4周龄（未断奶）：每2-3小时喂一次猫用羊奶粉（绝不能用牛奶）
- 4-8周龄：羊奶粉+幼猫罐头/泡软幼猫粮的糊状物
- 2-4月龄：每天喂4次幼猫粮（可泡软），逐步过渡到干粮
- 4-12月龄：每天喂3次幼猫粮
- 12月龄后：过渡到成猫粮

### 3.2 猫砂训练
- 大多数猫天生会埋屎，只需把猫砂盆放在安静通风处
- 幼猫到家后，饭后和睡醒后把它放进猫砂盆，它会自己学会
- 猫砂盆数量 = 猫数量 + 1（两只猫需要三个猫砂盆）
- 每天铲屎1-2次，每周彻底清洗一次猫砂盆
- 不要频繁更换猫砂品牌/类型，猫很挑剔

### 3.3 猫咪疫苗
- 8周龄：第一针猫三联（猫瘟+猫鼻支+猫杯状）
- 12周龄：第二针猫三联
- 16周龄：第三针猫三联 + 狂犬疫苗
- 之后每年加强一次

## 四、社会化训练

### 4.1 关键期
- 狗的社会化关键期：3-14周龄（这个阶段接触的事物会影响一生的性格）
- 猫的社会化关键期：2-7周龄
- 在关键期内尽量让幼宠接触：不同年龄的人、其他友善的动物、各种声音（吸尘器/雷声/鞭炮声）、不同地面材质、汽车/电梯等

### 4.2 狗狗基础训练
- 名字识别：叫名字+给零食，重复直到它听到名字就看你
- 定点排便：选定区域铺尿垫，观察信号（转圈/闻地面），及时抱过去+排便后立刻奖励
- 笼内训练：笼子=安全屋，放零食和玩具进去让它主动进入，逐渐关门延长时长
- 基础指令：坐下、等待、过来、放下，每个指令用零食引导，每天练5-10分钟
- 社会化训练：完成疫苗后，每天带出去接触不同的环境和狗

### 4.3 常见行为问题
- 咬手/咬脚：幼犬探索世界的方式，不要用手当玩具，用玩具替代，咬手时发出"哎"声停止互动
- 分离焦虑：从短时间离开开始训练，离开时不要有告别仪式，回来后等它冷静再互动
- 乱叫：排除生理需求后，不要对叫声做出反应（不看、不摸、不说话），安静后才奖励
- 护食：手喂建立信任，吃饭时偶尔加入更好的零食，让它知道人手靠近=好事

## 五、绝育

### 5.1 绝育时间
- 狗：6-9月龄（小型犬可稍早，大型犬建议骨骼发育完成后）
- 猫：6-8月龄（体重达到2kg以上）
- 发情期不建议手术（血管充血风险高），等发情结束后2-4周

### 5.2 绝育好处
- 母犬/母猫：消除子宫蓄脓风险、大幅降低乳腺肿瘤概率、避免假孕
- 公犬/公猫：消除睾丸癌风险、减少前列腺问题、减少标记领地行为
- 整体：减少因发情导致的走失/跳楼/攻击行为，延长寿命1-3年

### 5.3 术后护理
- 戴伊丽莎白圈7-10天防止舔伤口
- 术后当天可能呕吐/嗜睡属正常反应
- 保持伤口干燥，每天检查有无红肿渗液
- 术后24小时恢复喂食（先少量），48小时恢复饮食
- 限制运动2周，不要跳上跳下
- 拆线（如需）通常在术后10-14天

## 六、日常健康管理

### 6.1 每日观察清单
- 精神状态：是否活跃、对周围感兴趣
- 食欲：是否正常进食，突然拒食超过24小时需就医
- 饮水量：突然大量饮水可能是糖尿病/肾病信号
- 排便：成形、颜色正常（棕色），腹泻/带血/黑色需关注
- 排尿：频率和量正常，频繁蹲尿/尿血需就医
- 呼吸：平稳无杂音，腹式呼吸或张嘴呼吸（猫）是异常信号
- 被毛：有光泽、无脱毛区、无皮屑

### 6.2 体重管理
- 理想体态：肋骨可摸到但看不到，腰身明显（俯视）
- 过瘦：肋骨明显可见、脊椎突出→增加喂食量+排查疾病
- 过胖：摸不到肋骨、俯视无腰身→减少喂食量10-15%+增加运动
- 肥胖危害：关节疾病、糖尿病、心脏病、寿命缩短
- 建议每月称一次体重并记录

### 6.3 体检频率
- 幼宠（1岁以下）：每3个月一次
- 成宠（1-7岁）：每年1次
- 老年宠（7岁以上）：每半年1次
- 常规体检项目：血常规、生化全项、尿检、粪检、影像学（X光/B超）

## 七、宠物保险

### 7.1 是否有必要
- 宠物看病没有医保，一次手术可能花费3000-20000元
- 如果经济储备不充裕，建议购买宠物医疗险
- 月均保费约50-200元，可覆盖大部分常见疾病的诊疗费用

### 7.2 选购要点
- 等待期：购买后通常有30天等待期（意外伤除外），期间生病不赔
- 免赔额：每次理赔有200-500元免赔额
- 赔付比例：通常60%-80%
- 年度限额：注意年度总赔付上限
- 既往症：投保前已有的疾病不赔
- 定点医院：确认家附近宠物医院是否在定点列表中

## 八、紧急情况判断

### 8.1 必须立即就医的信号
- 呼吸困难：张嘴呼吸（狗非散热情况）、腹部剧烈起伏
- 持续呕吐/腹泻：一天超过3次或带血
- 抽搐/癫痫：持续超过2分钟或反复发作
- 中毒症状：误食巧克力/葡萄/药物后出现呕吐、流涎、震颤
- 无法排尿：蹲厕但无尿排出（尤其公猫，可能是尿道堵塞，24小时内致命）
- 体温异常：犬猫正常体温37.5-39.2°C，超过40°C或低于36°C需急救
- 严重外伤：大量出血、骨折、从高处坠落
- 腹部急剧膨胀：可能是胃扭转（大型犬致命急症）

### 8.2 可以观察的情况
- 偶尔呕吐1次但精神食欲正常
- 轻微软便但无血、精神好
- 偶尔打喷嚏但无鼻涕
- 轻微皮肤发红但精神食欲正常
- 跛行但能负重、无肿胀
