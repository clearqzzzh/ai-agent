# 🐶 狗狗喂养知识库

---

## 🚫 狗狗绝对不能吃的食物

| 食物 | 危害 |
|:---|:---|
| 巧克力、咖啡、茶 | 含可可碱和咖啡因，**对狗有剧毒，少量即可致死** |
| 洋葱、大蒜、韭菜 | 破坏红细胞，导致溶血性贫血 |
| 葡萄、葡萄干 | 可导致**急性肾衰竭**，几颗就可能致命 |
| 木糖醇 | 常见于口香糖、牙膏、花生酱，引起致命性低血糖 |
| 牛油果 | 含 persin，对狗有毒，引起呕吐腹泻 |
| 生面团、发酵面团 | 在胃里膨胀 + 产生酒精，双重危险 |
| 酒精及含酒精食物 | 损伤肝脏和大脑 |
| 夏威夷果 | 引起虚弱、呕吐、体温升高 |
| 含盐量高的食物 | 导致钠离子中毒，加重肾脏负担 |
| 鸡骨头、鱼骨头 | 煮熟后易碎裂，**划伤食道和肠道** |

## 不同体型犬的喂养差异

| 体型 | 代表品种 | 特点与建议 |
|:---|:---|:---|
| **小型犬** | 泰迪、比熊、吉娃娃 | 代谢快，需高能量密度狗粮、颗粒小；每日2-3次，注意低血糖风险 |
| **中型犬** | 边牧、柴犬、柯基 | 运动量大，均衡蛋白质和碳水；柯基易胖，**严格控制食量** |
| **大型犬** | 金毛、拉布拉多、德牧 | 生长期长达18-24个月，需大型犬幼犬配方；控制钙磷比防骨骼畸形 |
| **超大型犬** | 阿拉斯加、大白熊、圣伯纳 | 生长缓慢，幼犬期**禁止过量补钙**，易致髋关节发育不良 |

## 幼犬营养需求

幼犬在3-12个月是快速生长期：

- 需要**高蛋白（不低于28%）**、适量脂肪（12%-18%）
- 大型犬幼犬需专门钙磷比（**1.2:1 到 1.4:1**），避免骨骼发育过快导致关节问题
- 每天喂食 **3-4次**，少食多餐，不要一次喂太多

## 科学换粮方法——7日换粮法

突然换粮会导致狗狗呕吐、腹泻、食欲下降。正确做法：

| 阶段 | 旧粮比例 | 新粮比例 |
|:---|:---:|:---:|
| 第1-2天 | 75% | 25% |
| 第3-4天 | 50% | 50% |
| 第5-6天 | 25% | 75% |
| 第7天 | 0% | 100% |

> ⚠️ 换粮期间密切观察狗狗粪便情况，软便或腹泻应放缓节奏。
> 
> 肠胃敏感的狗狗可延长到 **10-14天**。

## 狗粮储存方法

狗粮开封后极易受潮变质，必须密封保存：

1. 使用**密封储粮桶**（非原包装袋直接存放）
2. 放置食品级干燥剂
3. 存放在阴凉干燥处，避免阳光直射
4. 不要一次性倒出太多，避免反复开盖
5. 开封后的狗粮尽量在 **6-8周内** 吃完

> 📦 大包装狗粮建议**分装成小包**，减少与空气接触次数。
> 
> 湿粮/罐头开封后需冷藏，并在 **24-48小时** 内食用完毕。

## 狗狗每日喂食量参考（干粮）

| 阶段 | 每日喂食量 |
|:---|:---|
| 2-3个月幼犬 | 体重的 5%-6% |
| 4-6个月幼犬 | 体重的 4%-5% |
| 7-12个月狗狗 | 体重的 3%-4% |
| 成年小型犬（<10kg） | 80-150g（视品牌和活动量调整） |
| 成年中型犬（10-25kg） | 200-350g |
| 成年大型犬（>25kg） | 350-600g |

> 以上为参考量，实际喂食需结合狗粮包装建议和狗狗个体情况。活动量大的工作犬、运动犬需额外增加 **20%-30%**。

## 狗狗常见健康问题的饮食建议

| 问题 | 高发品种 | 饮食建议 |
|:---|:---|:---|
| 皮肤敏感 / 过敏 | — | 选**单一肉源**低敏配方（鸭肉、鹿肉），避免鸡肉、牛肉 |
| 关节问题 | 金毛、德牧 | 选含**葡萄糖胺和软骨素**的狗粮，控制体重 |
| 泪痕严重 | 比熊、马尔济斯 | 选无人工色素、**低盐**配方，配合勤擦眼周 |
| 牙结石 / 口臭 | — | 选**大颗粒**狗粮增加咀嚼摩擦，配合洁齿骨和定期刷牙 |
| 胰腺炎史 | — | 严格**低脂饮食**（脂肪 < 10%），禁食高油脂类食物 |
| 肠胃敏感 | 德牧、阿拉斯加 | 选含**益生菌和益生元**的狗粮，避免谷物含量高的配方 |

## 狗粮类型对比

| 类型 | 优点 | 缺点 | 适用场景 |
|:---|:---|:---|:---|
| 干粮 | 方便储存、价格适中、有助于牙齿清洁 | 含水量低（约10%），加工温度高 | 日常主食，最普遍的选择 |
| 湿粮/罐头 | 含水量高（75%），适口性好，蛋白质丰富 | 价格高，开封需冷藏，长期吃易牙垢 | 挑嘴犬、病后恢复、老年犬 |
| 鲜粮/自制 | 食材可见可控，无防腐剂 | 营养配比难精确，费时费钱 | 有时间且懂营养的主人 |
| 生骨肉（BARF） | 最接近自然饮食，毛发光泽、便便不臭 | 寄生虫/细菌风险高，配比严格 | 有经验的喂养者，需冷冻72h以上 |
| 冻干粮 | 营养保留好，复水后适口性佳 | 价格最高 | 高端喂养、挑嘴犬 |

> 大多数家庭养犬推荐**干粮为主+偶尔搭配湿粮**的方式，兼顾营养均衡和口腔健康。

## 狗狗饮水量

狗狗比猫咪更爱喝水，但仍然需要保证充足的清洁饮水：

- 每日建议饮水量：**每公斤体重50-100ml**（一只10kg的狗每天需要500-1000ml水）
- 运动后、夏天、吃干粮的狗狗需要更多水
- 饮水不足的表现：牙龈干燥、尿液深黄色、精神萎靡、皮肤弹性差
- 饮水过多也要警惕：可能是糖尿病、肾脏疾病或子宫蓄脓的信号
- 水碗每天清洗换水，保持水质新鲜
- 出门遛狗时携带便携水碗，尤其夏天防止中暑
- 大型犬剧烈运动后不要立刻大量饮水，分次少量供给，防止胃扭转

## 狗狗肥胖问题与减肥饮食

超过40%的家养犬超重，肥胖会缩短狗狗寿命2-3年，并增加关节炎、糖尿病、心脏病的风险。

- 理想体态评分（BCS 4-5/9）：能看到腰部曲线，摸得到肋骨但看不到，腹部有适度收紧
- 容易发胖的品种：拉布拉多、柯基、比格犬、巴哥、腊肠犬
- 减肥方法：
  - 每日喂食量减少10%-20%，循序渐进
  - 选择高蛋白低脂肪的减肥狗粮（脂肪含量<10%）
  - 增加运动量：每天至少30-60分钟中等强度运动
  - 停止喂食人类食物（这是肥胖的最大元凶）
  - 零食换成低热量替代品（胡萝卜条、苹果片）
- 减肥速度：每月减重不超过体重的3%，过快会损失肌肉
- 每2周称重一次，记录体重变化曲线

## 老年犬喂养注意事项（7岁以上，大型犬6岁以上）

老年犬的代谢率下降，器官功能逐渐衰退：

- 换成老年犬专用粮，蛋白质适中（20-25%），脂肪含量降低（8-12%）
- 关节问题高发，补充葡萄糖胺、软骨素和鱼油（Omega-3）
- 肾脏负担增大，选低磷低钠配方，定期检查肾功能
- 食欲下降时：加热食物增加香气、加温水泡软干粮、搭配少量湿粮
- 每天喂食2次，定时定量，避免自由采食导致过饱
- 牙齿问题严重的老年犬，改喂软食或湿粮
- 便秘常见：增加膳食纤维（南瓜泥），保证充足饮水
- 认知功能下降（老年痴呆）：补充DHA和抗氧化剂（维生素E、C）

## 狗狗挑食怎么办

狗狗突然不吃饭，先排查疾病原因（口腔问题、肠胃不适、发热），确认健康后：

- 定时定量喂食：放饭15-20分钟后收走，下一顿再给
- 不要一不吃就换粮——这会让狗狗学会"不吃就有更好的"
- 停止所有零食和人类食物，饿1-2顿（健康成犬可以），让它明白饭点才有饭吃
- 食物加热到37°C增加香气
- 检查狗粮是否受潮变质（闻起来有哈喇味就该扔了）
- 增加运动量：运动后的狗狗食欲更好
- 换粮遵循7日换粮法，不要突然更换
- 如果持续3天以上完全拒食，立即就医

## 孕犬和哺乳期母犬喂养

怀孕期和哺乳期的母犬营养需求大幅增加：

- 怀孕前6周：正常喂食即可，不需要额外加量
- 怀孕第7-9周（最后3周）：逐渐增加喂食量至平时的1.5倍
- 哺乳期：母犬热量需求达到平时的2-3倍，自由采食或每天喂3-4次
- 选择高蛋白高能量的幼犬粮或孕犬专用粮（蛋白质≥28%，脂肪≥15%）
- 补充钙质和DHA，但怀孕中后期不要过量补钙（防止低血钙症）
- 充足饮水对泌乳至关重要
- 产后母犬食欲恢复需要3-5天，期间提供易消化的食物

## 狗狗营养补充剂

均衡饮食的健康狗狗通常不需要额外补充，但以下情况建议考虑：

- **鱼油/Omega-3**：皮肤干燥、掉毛严重、关节问题的狗狗，改善皮毛质量和抗炎
- **益生菌**：换粮、腹泻后、使用抗生素后补充，恢复肠道菌群平衡
- **葡萄糖胺+软骨素**：大型犬、老年犬、有关节问题的品种（金毛、德牧），保护关节软骨
- **卵磷脂**：促进毛发健康，改善皮肤屏障功能
- **维生素E**：老年犬抗氧化补充，增强免疫力
- **钙片**：仅在兽医指导下使用，过量补钙对大型犬幼犬危害极大

> 补充剂是"补充"不是"替代"，优先保证主粮营养均衡。盲目补充可能适得其反。

## 运动与喂食时间的关系

科学的运动与喂食安排能预防致命的胃扭转（GDV）：

- 饭后至少休息1小时再运动，大型犬建议1.5-2小时
- 剧烈运动后至少休息30分钟再喂食/饮水
- 每天遛狗2次，每次30-60分钟（小型犬15-30分钟即可）
- 幼犬（12个月以下）避免长时间跑步和跳高，保护发育中的骨骼关节
- 短鼻犬（法斗、巴哥、英斗）夏天避免中午遛狗，容易中暑
- 大型犬深胸犬（金毛、德牧、大丹）是胃扭转高危品种，必须严格遵守运动与喂食间隔
- 老年犬减少剧烈运动，改为慢走和游泳等低冲击运动
