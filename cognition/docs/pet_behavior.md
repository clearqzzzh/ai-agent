# 宠物行为与训练指南

## 犬行为学基础

### 犬的社交行为

**等级制度：**
- 犬是群居动物，有等级意识
- 不是"阿尔法狗"理论（已修正）
- 更准确说是资源控制关系
- 通过一致规则建立信任

**社交信号：**

安定信号（缓解紧张）：
- 舔鼻子
- 打哈欠
- 转头/转身
- 缓慢移动
- 坐下/躺下
- 嗅地面

友好信号：
- 摇尾巴（放松、全身摇摆）
- 鞠躬姿势（前肢趴下，屁股翘起）
- 舔脸
- 翻肚皮（信任）

警告信号：
- 低吼
- 露齿
- 毛发竖起
- 身体僵硬
- 直视
- 尾巴高举僵硬

**误解：**
- 摇尾巴≠一定友好（可能紧张）
- 翻肚皮≠求摸（可能是安抚）
- 打哈欠≠困（可能是压力）

### 常见问题行为

#### 分离焦虑

**症状：**
- 主人离开时嚎叫、吠叫
- 破坏家具、门框
- 室内排泄
- 过度舔舐（自残）
- 试图逃跑

**原因：**
- 过早离开母犬
- 多次更换主人
- 创伤经历
- 缺乏独立训练

**改善方法：**
- 渐进式脱敏（短时间离开→逐渐延长）
- 离开时不戏剧化（不告别、不夸张迎接）
- 提供安全感物品（有主人气味的衣服）
- 消耗精力（离开前运动）
- 益智玩具（分散注意力）
- 严重时遵医嘱用药

#### 过度吠叫

**原因：**
- 警戒/领地保护
- 无聊/寻求关注
- 焦虑/恐惧
- 回应其他犬
- 需求（要出去、要食物）

**处理：**
- 找出原因（记录吠叫情境）
- 不奖励吠叫（不关注、不给食物）
- 奖励安静
- 充足运动和刺激
- 训练"安静"指令
- 避免惩罚（增加焦虑）

#### 破坏行为

**原因：**
- 幼犬换牙期
- 无聊/精力过剩
- 分离焦虑
- 探索行为

**处理：**
- 提供合适咀嚼玩具
- 充足运动
- 环境管理（收好贵重物品）
- 不要事后惩罚（犬无法关联）
- 当场抓到时redirect到玩具

#### 扑人

**原因：**
- 兴奋 greeting
- 寻求关注
- 幼年行为延续

**处理：**
- 转身不理（不关注）
- 四脚着地才奖励
- 训练替代行为（坐下greeting）
- 客人配合（不关注扑人的犬）

### 资源守护

**表现：**
- 护食
- 护玩具
- 护人
- 护地盘

**处理：**
- 不要惩罚（加剧守护）
- 交换游戏（给更好的换走）
- 脱敏训练（接近时给更好的）
- 幼犬期预防（手伸食盆加食物）
- 严重时寻求专业帮助

## 猫行为学基础

### 猫的天性

**领地动物：**
- 对领地变化敏感
- 新环境需要时间适应
- 垂直空间很重要

**晨昏活动：**
- 黎明黄昏最活跃
- 白天大部分时间睡觉（12-16小时）
- 夜间活动可能打扰主人

**狩猎本能：**
- 追逐移动物体
- 扑咬手脚（玩耍）
- 需要狩猎模拟游戏

### 常见问题行为

#### 乱尿

**医学原因（先排除）：**
- 泌尿道疾病
- 糖尿病
- 肾病
- 关节炎（进出猫砂盆困难）

**行为原因：**
- 猫砂盆问题（脏、位置、类型）
- 应激（环境变化、新宠物）
- 标记行为（未绝育）
- 对猫砂材质不满

**处理：**
- 先就医排除疾病
- 增加猫砂盆数量（n+1原则）
- 每天清理
- 尝试不同猫砂
- 减少应激
- 绝育（标记行为）

#### 抓家具

**原因：**
- 磨爪需求（天性）
- 标记领地
- 伸展身体

**处理：**
- 提供猫抓板（多种类型）
- 放在显眼位置
- 奖励使用猫抓板
- 家具贴防抓贴
- 定期剪指甲
- 不要惩罚（增加压力）

#### 攻击行为

**类型：**
- 玩耍攻击（幼猫常见）
- 恐惧攻击
- 疼痛攻击
- 转移攻击
- 领地攻击

**处理：**
- 不用手脚玩耍（用玩具）
- 被咬时停止互动
- 找出触发因素
- 充足游戏时间
- 多猫家庭注意资源分配

#### 夜间活动

**原因：**
- 天性晨昏活动
- 白天睡太多
- 饥饿

**处理：**
- 睡前大量游戏
- 睡前喂食
- 白天增加刺激
- 自动玩具
- 不要夜间回应（强化行为）

## 训练基础

### 训练原则

**正向强化：**
- 奖励期望行为
- 忽略或redirect不期望行为
- 避免惩罚（增加恐惧和攻击）

**时机：**
- 奖励在行为发生后1-2秒内
- 过晚奖励无效
- 使用标记词（"好"）或响片

**一致性：**
- 全家统一规则
- 同一指令同一含义
- 每天短时间训练（5-10分钟）

**耐心：**
- 每只宠物学习速度不同
- 复杂行为需要分解
- 重复是关键

### 基础指令训练

#### 坐下

**步骤：**
1. 拿零食靠近鼻子
2. 缓慢向上向后移动
3. 犬自然坐下
4. 说"坐"
5. 立即奖励
6. 重复练习

**常见问题：**
- 跳起来抢→零食放低
- 后退→靠墙练习
- 不感兴趣→换高价值零食

#### 等待/停留

**步骤：**
1. 先坐下
2. 手掌向前说"等"
3. 后退一步
4. 回来奖励
5. 逐渐增加距离和时间

**注意：**
- 循序渐进
- 失败时退回上一步
- 不要惩罚移动

#### 过来

**步骤：**
1. 用长牵引绳
2. 蹲下张开手臂
3. 说"来"
4. 过来后大量奖励
5. 逐渐增加距离和干扰

**关键：**
- 永远不要在叫回来后惩罚
- 让回来成为最棒的事
- 高价值奖励

#### 松绳行走

**问题：**
- 犬拉绳是自然行为（走得快）
- 需要训练而非惩罚

**方法：**
- 拉绳时停下
- 松绳时继续走
- 犬回到身边时奖励
- 使用合适装备（胸背带）
- 耐心（可能需要数月）

### 猫训练

**猫可以训练吗？**
- 可以，但动机不同
- 食物驱动（找到高价值零食）
- 短时间（猫注意力短）
- 尊重猫的意愿

**可训练行为：**
- 过来
- 坐下
- 击掌
- 进航空箱
- 接受刷牙/剪指甲

**方法：**
- 响片训练效果好
- 饭前训练（更有动力）
- 每次1-3分钟
- 结束在成功时

## 社会化

### 犬社会化

**关键期：**
- 3-14周龄是黄金期
- 此阶段接触的事物影响终身
- 错过关键期仍可训练但更难

**接触内容：**
- 不同人（男女老少、戴帽子、拄拐杖）
- 不同犬（大小、品种）
- 不同环境（街道、公园、车内）
- 不同声音（吸尘器、雷声、烟花）
- 不同地面（草地、瓷砖、金属）

**原则：**
- 正面体验（零食、玩具）
- 不强迫（让犬自己探索）
- 观察压力信号
- 循序渐进

### 猫社会化

**关键期：**
- 2-7周龄
- 比犬短，更早

**接触内容：**
- 不同人（温柔对待）
- 不同环境（房间、高处）
- 不同声音
- 其他猫（如多猫家庭）
- 航空箱、汽车

**注意：**
- 猫更敏感，不要过度刺激
- 提供安全藏身处
- 尊重猫的界限

## 多宠物家庭

### 引入新宠物

**犬引入新犬：**
- 中立地点见面
- 平行行走
- 观察身体语言
- 回家分开区域
- 逐渐增加相处时间

**猫引入新猫：**
- 隔离开始（单独房间）
- 交换气味（毛巾、玩具）
- 门缝见面
- 短时间 supervised见面
- 逐渐延长
- 可能需要数周

**犬猫共处：**
- 选择猫友好犬种
- 幼犬期引入最佳
- 训练犬"leave it"
- 猫有高处逃生路线
- 永远不要强迫互动

### 资源管理

**原则：**
- 足够资源（食盆、水盆、猫砂盆、休息处）
- n+1原则（猫砂盆数量=猫数量+1）
- 分散放置
- 观察是否有资源守护

### 嫉妒/竞争

**症状：**
- 攻击新宠物
- 行为退化（室内排泄）
- 过度寻求关注
- 食欲下降

**处理：**
- 公平对待
- 单独相处时间
- 不比较
- 各自资源
- 耐心（可能需要数月适应）

## 老年宠物行为变化

### 认知功能障碍

**症状：**
- 定向力障碍（迷路、发呆）
- 昼夜节律紊乱（夜间嚎叫）
- 社交行为改变
- 大小便失禁
- 食欲改变

**管理：**
- 保持规律作息
- 不改变家具布局
- 夜灯帮助导航
- 益智玩具保持刺激
- 耐心和理解

### 疼痛相关行为

**识别：**
- 不愿运动
- 攻击性增加
- 舔咬某部位
- 姿势改变
- 食欲下降

**处理：**
- 就医检查
- 疼痛管理
- 环境调整（防滑垫、低边猫砂盆）
- 辅助工具（ ramps、orthopedic床）

## 行为问题何时寻求专业帮助

**需要专业行为师的情况：**
- 攻击行为（咬人、严重咬伤）
- 严重分离焦虑
- 自残行为
- 恐惧症严重影响生活
- 多宠物家庭严重冲突
- 训练无效的行为问题

**寻找专业帮助：**
- 认证动物行为师
- 兽医行为专科
- 正向训练师
- 避免使用惩罚/电击项圈的训练师
