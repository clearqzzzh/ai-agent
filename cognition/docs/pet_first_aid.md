# 宠物急救与应急处理手册

## 急救基本原则

### 急救优先级

**第一优先（立即处理）：**
- 呼吸停止 → 人工呼吸
- 心跳停止 → 心肺复苏
- 大出血 → 止血
- 气道阻塞 → 清除异物

**第二优先（尽快处理）：**
- 骨折 → 固定
- 中毒 → 解毒/催吐
- 烧伤 → 冷却
- 休克 → 保温、补液

**第三优先（稳定后处理）：**
- 伤口清洁
- 疼痛管理
- 后续治疗

### 急救箱准备

**必备物品：**
- 无菌纱布、绷带、胶带
- 生理盐水（冲洗伤口）
- 碘伏或氯己定（消毒）
- 剪刀、镊子
- 体温计（宠物专用）
- 一次性手套
- 伊丽莎白圈
- 止血粉
- 宠物专用药物（遵医嘱）

**可选物品：**
- 毛毯（保温）
- 木板（骨折固定）
- 注射器（喂药/喂水）
- 宠物急救手册
- 兽医急诊电话

### 紧急情况判断

**立即就医信号：**
- 呼吸困难或停止
- 心跳停止
- 大出血不止
- 意识丧失
- 抽搐持续超过5分钟
- 疑似中毒
- 无法排尿（公猫尿闭）
- 体温过高（>41°C）或过低（<36°C）
- 严重创伤
- 眼睛受伤

**可在家观察：**
- 轻微擦伤
- 轻度腹泻（<24小时）
- 偶尔呕吐（<3次/天）
- 轻微跛行
- 食欲暂时下降

## 心肺复苏（CPR）

### 判断是否需要CPR

**检查意识：**
- 轻拍、呼唤宠物
- 无反应→检查呼吸

**检查呼吸：**
- 观察胸部起伏
- 感觉鼻孔气流
- 无呼吸→开始人工呼吸

**检查心跳：**
- 触摸大腿内侧股动脉
- 或左胸肘后心跳位置
- 无心跳→开始胸外按压

### 人工呼吸

**步骤：**
1. 将宠物右侧卧，头颈伸直
2. 清除口腔异物（血、呕吐物、分泌物）
3. 拉出舌头，避免阻塞气道
4. 闭合嘴巴，对着鼻孔吹气
5. 看到胸部隆起即可
6. 频率：每3-5秒一次（12-20次/分钟）

**注意事项：**
- 不要过度吹气（防止肺损伤）
- 小型犬/猫：用嘴完全包住鼻孔
- 大型犬：捏住嘴巴，对着鼻孔吹
- 每30次按压后2次人工呼吸

### 胸外按压

**位置：**
- 小型犬/猫：直接按压心脏位置（左胸肘后）
- 大型犬：按压最宽处胸部

**方法：**
- 一手放在另一手上
- 手臂伸直，垂直下压
- 深度：胸宽的1/3-1/2
- 频率：100-120次/分钟

**按压-通气比：**
- 30次按压 : 2次人工呼吸
- 或15:2（两人操作时）

**持续时间：**
- 持续直到宠物恢复心跳呼吸
- 或到达兽医诊所
- 一般不超过20分钟

### CPR后处理

**即使恢复心跳呼吸，也必须立即就医：**
- 可能有内伤
- 需要氧气支持
- 监测心律
- 治疗原发病

## 出血处理

### 出血类型

**动脉出血：**
- 鲜红色
- 喷射状
- 最危险
- 需立即止血

**静脉出血：**
- 暗红色
- 持续流出
- 较易控制

**毛细血管出血：**
- 渗出状
- 量少
- 通常自行停止

### 止血方法

**直接压迫法（首选）：**
1. 用无菌纱布覆盖伤口
2. 用手直接压迫
3. 持续压迫5-10分钟
4. 不要频繁查看（影响凝血）
5. 如浸透，在上面加新纱布（不要移除旧的）

**加压包扎法：**
1. 纱布覆盖伤口
2. 绷带加压包扎
3. 压力适中（能插入一指）
4. 定期检查远端循环（脚趾颜色、温度）

**止血带法（最后手段）：**
- 仅用于四肢大动脉出血
- 其他方法无效时使用
- 记录使用时间
- 每15-20分钟放松1-2分钟
- 可能导致肢体坏死

**止血粉/凝胶：**
- 适用于小伤口、指甲出血
- 直接按压在出血点
- 指甲剪出血常用

### 内出血识别

**症状：**
- 牙龈苍白
- 腹部肿胀
- 虚弱、嗜睡
- 呼吸急促
- 心跳加快
- 休克症状

**处理：**
- 立即就医
- 保持安静、保温
- 不要喂食喂水
- 尽快送医

## 中毒处理

### 常见毒物

**家庭毒物：**
- 巧克力（可可碱）
- 葡萄/葡萄干
- 洋葱/大蒜
- 木糖醇（无糖食品）
- 酒精
- 咖啡因
- 某些植物（百合、杜鹃、夹竹桃）
- 清洁剂、杀虫剂
- 人类药物（布洛芬、对乙酰氨基酚）

**症状：**
- 呕吐、腹泻
- 流涎、口腔灼伤
- 抽搐、震颤
- 虚弱、嗜睡
- 呼吸困难
- 昏迷

### 急救步骤

**1. 确认毒物：**
- 什么毒物？
- 多少量？
- 什么时候摄入的？
- 保留包装/样本

**2. 联系兽医：**
- 描述情况
- 遵医嘱处理
- 不要自行催吐（某些毒物催吐更危险）

**3. 催吐（仅遵医嘱）：**
- 3%双氧水（1ml/kg体重）
- 仅用于摄入后2小时内
- 腐蚀性物质禁止催吐
- 意识不清禁止催吐

**4. 活性炭：**
- 吸附毒物
- 遵医嘱使用
- 某些毒物无效（酒精、金属）

**5. 送医：**
- 带毒物包装
- 记录摄入时间和量
- 尽快到达

### 特定毒物处理

**巧克力中毒：**
- 计算可可碱摄入量
- 黑巧克力毒性最强
- 催吐（如刚摄入）
- 活性炭
- 支持治疗

**木糖醇中毒：**
- 极少量即可中毒
- 导致低血糖、肝衰竭
- 立即就医
- 可能需要葡萄糖输注

**葡萄/葡萄干中毒：**
- 机制不明
- 导致肾衰竭
- 催吐（如刚摄入）
- 积极补液保护肾脏

**对乙酰氨基酚（泰诺）中毒（猫）：**
- 猫极度敏感
- 导致高铁血红蛋白血症
- 立即就医
- 特效解毒剂（N-乙酰半胱氨酸）

## 创伤处理

### 擦伤/割伤

**处理：**
1. 止血（直接压迫）
2. 生理盐水冲洗
3. 碘伏消毒（从中心向外）
4. 包扎（如需）
5. 佩戴伊丽莎白圈（防止舔咬）

**就医信号：**
- 伤口深、长、宽
- 出血不止
- 伤口内有异物
- 动物咬伤
- 面部、关节处伤口

### 烧伤/烫伤

**分级：**
- 一度：皮肤红肿、疼痛
- 二度：水疱、剧烈疼痛
- 三度：皮肤发白/焦黑、可能无痛（神经损伤）

**处理：**
1. 立即冷却（凉水冲洗10-20分钟）
2. 不要冰敷（加重损伤）
3. 不要涂抹油膏、牙膏
4. 用干净纱布覆盖
5. 立即就医（二度以上）

**化学烧伤：**
- 大量清水冲洗
- 至少15-20分钟
- 带化学品包装就医

### 骨折

**识别：**
- 肢体变形
- 异常活动
- 肿胀、疼痛
- 不敢承重
- 骨摩擦音

**处理：**
1. 限制活动（不要试图复位）
2. 用木板/硬纸板固定
3. 固定范围包括上下关节
4. 软垫保护
5. 立即就医

**脊柱损伤：**
- 怀疑脊柱损伤时不要移动
- 用硬板平移
- 保持脊柱稳定
- 立即就医

### 眼睛受伤

**常见类型：**
- 角膜擦伤
- 异物进入
- 化学灼伤
- 眼球突出

**处理：**
- 佩戴伊丽莎白圈（防止揉眼）
- 生理盐水冲洗（异物/化学物）
- 不要自行用药
- 立即就医

**眼球突出：**
- 保持湿润（生理盐水纱布）
- 不要试图推回
- 立即急诊

## 休克处理

### 识别

**症状：**
- 牙龈苍白/发灰
- 心跳加快（>160次/分钟犬，>200次/分钟猫）
- 呼吸急促
- 四肢冰凉
- 虚弱、嗜睡
- 毛细血管充盈时间延长（>2秒）

### 原因

- 大出血
- 严重创伤
- 过敏反应
- 中毒
- 严重感染
- 心脏疾病

### 急救

1. 止血（如出血）
2. 保温（毛毯）
3. 保持呼吸道通畅
4. 抬高后肢（增加回心血量）
5. 不要喂食喂水
6. 立即就医

## 中暑处理

### 识别

**症状：**
- 体温>40°C
- 剧烈喘气
- 流涎增多
- 牙龈鲜红/发紫
- 虚弱、步态不稳
- 呕吐、腹泻
- 抽搐、昏迷

### 高风险群体

- 短鼻犬（法斗、英斗、巴哥）
- 肥胖宠物
- 老年宠物
- 黑色毛发宠物
- 心脏病宠物

### 急救

1. 立即转移到阴凉处
2. 用凉水（不是冰水）淋湿身体
3. 风扇吹风加速散热
4. 提供饮水（不要强迫）
5. 监测体温（降到39.5°C停止降温）
6. 立即就医（即使症状缓解）

**注意事项：**
- 不要用冰水（血管收缩，散热更慢）
- 不要过度降温（导致低体温）
- 即使恢复也要就医（可能有器官损伤）

### 预防

- 避免高温时段外出
- 提供充足饮水和阴凉
- 不要将宠物留在车内
- 短鼻犬特别注意
- 地面温度测试（手背贴地5秒，烫则不能走）

## 低体温处理

### 识别

**症状：**
- 体温<36°C
- 颤抖（严重时停止）
- 嗜睡、虚弱
- 心跳呼吸减慢
- 僵硬
- 昏迷

### 急救

1. 转移到温暖环境
2. 用毛毯/毛巾包裹
3. 热水袋（裹毛巾，避免烫伤）
4. 温暖液体（如清醒可饮）
5. 监测体温
6. 就医

**注意事项：**
- 缓慢复温（过快导致心律失常）
- 不要直接加热四肢（冷血回流心脏）
- 昏迷宠物不要喂水

## 抽搐处理

### 识别

**症状：**
- 四肢划水样运动
- 意识丧失
- 流涎、大小便失禁
- 持续30秒-5分钟

### 常见原因

- 癫痫
- 中毒
- 低血糖
- 脑部疾病
- 高热
- 肝肾功能衰竭

### 急救

1. 保持冷静
2. 移开周围危险物品
3. 不要把手伸进嘴里（不会咬舌）
4. 记录抽搐时间和表现
5. 保持环境安静、昏暗
6. 抽搐停止后就医

**立即就医：**
- 首次抽搐
- 持续>5分钟
- 连续抽搐（间期<5分钟）
- 呼吸困难
- 疑似中毒

## 窒息处理

### 识别

**症状：**
- 呼吸困难、喘鸣
- 用爪抓嘴
- 牙龈发紫
- 恐慌
- 意识丧失

### 急救

** conscious宠物：**
1. 打开口腔检查
2. 如看到异物，用镊子取出
3. 不要盲掏（可能推更深）
4. 如看不到，尝试海姆立克法

**海姆立克法（犬）：**
- 小型犬：倒提，拍背
- 大型犬：从背后环抱，向上向内按压腹部
- 重复直到异物排出

**海姆立克法（猫）：**
- 倒提，拍背
- 或侧卧，按压腹部

**无意识宠物：**
- 开始CPR
- 每次人工呼吸前检查口腔
- 立即就医

## 运输受伤宠物

### 原则

- 保持安静、稳定
- 避免加重损伤
- 尽快送医

### 方法

**小型宠物：**
- 用毛巾/毛毯包裹
- 放入航空箱/纸箱
- 固定防止移动

**大型宠物：**
- 用毛毯/木板作为担架
- 两人以上搬运
- 保持脊柱稳定

**骨折宠物：**
- 固定骨折部位
- 用硬板运输
- 避免颠簸

**脊柱损伤：**
- 硬板平移
- 保持脊柱直线
- 不要弯曲扭转

### 途中注意事项

- 保持呼吸道通畅
- 监测呼吸心跳
- 保温
- 提前联系医院
- 规划最快路线
